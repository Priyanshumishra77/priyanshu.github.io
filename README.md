## Professional focus

I am a CPU/SoC design-verification engineer with nearly five years of hands-on experience across RISC-V processor verification, SoC IP verification, custom DSP/ASIP HW/SW co-verification, and processor architecture.

Current work: ACL Digital, on a Renesas client project involving custom DSP/ASIP verification, compiler-generated workloads, and ISS-to-RTL functional/architectural correlation.

Previous work includes NXP TrustZone-enabled AI SoC verification across eDMA5, AHBSC, MMU, LLC, and PMUX; RISC-V processor verification for Codasip; and CVA6/Ariane and Intel-related verification work.

For the current career summary, see the [web CV](https://priyanshumishra77.github.io/priyanshu.github.io/cv/).

## Built with

This site uses the [Academic Pages](https://academicpages.github.io/) project, built on Jekyll and the Minimal Mistakes theme. The original theme and project attribution and licensing are retained in this repository.

## Run locally

1. Install Ruby, Bundler, and Node.js.
2. Clone this repository.
3. Install Ruby dependencies with `bundle install`.
4. Start the local server with `bundle exec jekyll serve --livereload`.
5. Open <http://localhost:4000/priyanshu.github.io/>.

The repository is configured for the GitHub Pages project-site URL shown above; local preview URLs may differ depending on the Jekyll configuration.
